# UGCMediaClips brand

**Mark:** a stack of three vertical (9:16) shorts. The front one shows a play button and a caption bar. It stands for many clips from one source, captioned and ready to post.

| File | Use |
|---|---|
| `logo-mark.svg` | The mark, vector. Favicon, rail, avatars. |
| `logo-mark-1024.png` | The mark on a transparent background. |
| `app-icon-1024.png` | The mark on white, for app stores and social avatars. |
| `logo-light.png` / `logo-dark.png` | Mark + wordmark for light / dark backgrounds. |

- **Colours:** coral `#E5484D` (front card, "Clips"), `#FF8A8E` and `#FFC2C4` (back cards), ink `#19191A`, white.
- **Wordmark:** "UGC Media **Clips**" in Poppins ExtraBold (OFL, in `/fonts`), letter-spacing −2%, "Clips" in coral.
- **Product name** in text is written **UGCMediaClips**.
- **Below 20px**, the caption bar can be dropped (the favicon does this).
