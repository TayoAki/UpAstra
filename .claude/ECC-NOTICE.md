# Vendored from ECC

These skills and commands are copied unchanged from [affaan-m/ECC](https://github.com/affaan-m/ECC) at commit `76aaa77` (MIT License, see `ECC-LICENSE`):

- `skills/tdd-workflow`: test-first implementation of a `*.plan.md`
- `skills/verification-loop`: build, types, lint, tests, security grep and diff review, with a PASS/FAIL report
- `skills/santa-method`: two independent reviewers must both pass, with a fix-and-re-review loop
- `skills/search-first`: look for existing tools before writing code
- `skills/plan-orchestrate`: turn a plan into the right command per step
- `commands/plan-prd.md`, `commands/plan.md`: PRD → plan flow (`.claude/prds/`, `.claude/plans/`)

How UGCMediaClips uses them: see `clipper/docs/BUILD-PLAN.md` ("Working method").
